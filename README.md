# Cardify

Cardify là một ứng dụng web giáo dục hỗ trợ học tập và ghi nhớ kiến thức thông qua hệ thống thẻ ghi nhớ (Flashcard) thông minh. Dự án được xây dựng trên framework **Django** và tích hợp AI để tự động hóa quá trình tạo tài liệu học tập, mang lại trải nghiệm ôn thi hiệu quả và thú vị hơn.

## 🚀 Tính năng nổi bật (Key Features)

* **Quản lý Deck & Card:** Cho phép người dùng linh hoạt tạo, chỉnh sửa và sắp xếp các thẻ flashcard theo từng bộ (deck).
* **Tích hợp AI (Google Gemini):** Tự động trích xuất và tạo flashcard trực tiếp từ các tệp tài liệu (file) hoặc hình ảnh (image) người dùng tải lên.
* **Chế độ học tập đa dạng (Study Modes):** Hệ thống cung cấp các bài ôn tập tương tác để tối ưu hóa quá năng lực ghi nhớ.
* **Hệ thống Gamification:** Tạo động lực học tập với cơ chế điểm kinh nghiệm (XP), hệ thống cấp độ (leveling) và chế độ đấu trường (arena) cạnh tranh.
* **Tính năng cộng đồng:** Chia sẻ các bộ thẻ công khai (public decks) với người dùng khác, hỗ trợ công cụ quản lý từ vựng và import dữ liệu nhanh chóng.
* **Quản lý người dùng:** Đăng ký, đăng nhập và theo dõi tiến trình học tập cá nhân.

## 🛠 Công nghệ sử dụng (Tech Stack)

* **Backend:** Python, Django
* **AI Integration:** Google Gemini API
* **Frontend:** HTML, CSS, JavaScript (tùy chỉnh giao diện)
